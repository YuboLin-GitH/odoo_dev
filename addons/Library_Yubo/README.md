# Proyecto SGE: Módulo Library Yubo Odoo

## Descripción
Este repositorio contiene el código fuente del módulo personalizado **Library Yubo** desarrollado para el ERP Odoo. 
El módulo permite la gestión integral de una biblioteca, incluyendo:
- Gestión de **Libros**, **Autores**, **Géneros** y **Socios**.
- Sistema de **Préstamos** con fechas y validaciones.
- Vistas personalizadas (Tree, Form, **Kanban**).
- Integración con **API REST**.

## Tecnologías
- Python (ORM Odoo)
- XML (Vistas QWeb)
- Docker & Docker Compose
- Bootstrap
